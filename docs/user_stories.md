# User Stories
- I am a user who has just created a primitive in blender. I want to experiment with some new connector types, but they don't exist yet. I'd like to quickly create some new ones, define their pairs, and then generate some modules so I can see how they work in the grid. If this breaks the current setup, I can always delete the primitive and start again, if so, I want the option of deleting the connectors also.
- I am a user who is working quickly. I dont want to spend too much time making sure my work is perfect, I just want a quick start. I'd like to quickly create some primitive meshes, assign some basic materials, then have the addon acknowledge these materials as a placeholder. The addon should work with these placeholder materials. Failing that, if I can't be bothered to add materials, the addon should build some basic default mats for me to use, maybe it could ask me for a number of how many distinct mats to create.
